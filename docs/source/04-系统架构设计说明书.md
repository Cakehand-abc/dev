## 1 架构设计导论与目标原则

本文档遵循 IEEE 1471 与经典的 UML 4+1 架构视图模型，全面阐述智慧医养大数据决策分析系统的整体技术架构、关键子系统划分、模块接口契约与物理部署结构。系统设计贯彻高内聚低耦合、松耦合微内核、纵深安全防御、数据强一致性以及前后端分离的核心架构原则。

## 8 关键技术架构决策（ADR）

项目研发过程中经过深入技术评审，形成了一系列指导性架构决策：

| 架构决策项 | 决策背景与选型理由 | 技术影响与收益 |
| --- | --- | --- |
| Spring Boot 3.5.16 | 全面适配 Java 17 LTS 长期支持版，具备高效性能、卓越的容器化支持与成熟的测试生态。 | 统一通过 BOM 约束组件版本，确保项目构建高度平稳可靠。 |
| 模块化单体加 MySQL 8.0 | 针对中小型医养机构和校企实训场景，微服务架构会带来过高的分布式事务和运维复杂度，模块化单体是兼顾架构整洁与交付成本的最优解。 | 极大降低了跨节点 Session 同步与运维开销，确保了业务事务本地强一致。 |
| Vue 3 + Element Plus 前端 | 采用现代 Vue 3 组合式 API 与标准企业级组件库，具备极致的响应速度与丰富的交互组件库。 | 大幅提升了大屏图表、表单校验、地理画布与数据模拟面板的开发效率与维护性。 |
| 设备独立 X-Device-Key 协议 | 智能穿戴设备缺乏浏览器 Cookie 与 CSRF 机制，需采用轻量级轻态化鉴权。 | 采用设备级 SHA-256 签名凭证认证，支持密钥一键轮换与硬件解耦。 |
