## 1 测试用例设计方法与编制规范

本说明书测试用例严格遵循等价类划分法、边界值分析法、因果图判定表法以及状态迁移测试理论进行正规编制。全套用例涵盖认证鉴权、业务状态流转、并发乐观锁控制、海量数据分页与空间几何测距算法，直接映射至工程自动化测试源码 BusinessTests.java 与 DevApplicationTests.java。

| 测试层次 | 覆盖范围与核心测试域 | 执行机制与测试载体 |
| --- | --- | --- |
| 单元与集成测试 | RBAC 鉴权、数据一致性、状态机防抖、批量定位及接口幂等 | JUnit Jupiter 5.12.2 / Maven 构建 |
| 接口冒烟联调 | 16 项核心业务 RESTful API 与真实 MySQL 8.0 物理库联调 | Python 自动化冒烟测试套件 smoke_http.py |
| Web 端端验收 | 大盘渲染、数据模拟、受限删除与窄屏自适应响应 | Playwright 浏览器自动化脚本 v11-browser-qa.mjs |
| 高并发负载压测 | 双十万级历史数据基线，20 并发持续 60 秒高频压测 | Python 异步压测套件 performance_test.py |
