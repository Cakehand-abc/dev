# 项目报告一致性与架构图清单

更新时间：2026 年 9 月 9 日  
适用版本：V1.1

## 1. 核对结论

四份实训报告可用于理解成员学习过程和项目背景，但系统现状以当前仓库的代码、数据库脚本和验证证据为准。报告中提到的“问答 Agent”只出现在未来展望，不属于已实现功能。当前系统以确定性查询、统计分析、业务事务、设备接入和空间规则为主，不需要单设 Agent 开发工程师。

当前验收范围按十项功能描述：登录、首页、人口信息统计分析、健康检测统计分析、医生随访统计分析、腕表分布、电子围栏、轨迹回放、数据模拟、通用设备 GPS/心跳接入。批量轨迹注入和受限删除属于已有功能的增强能力，不重复计为独立导航模块。

## 3. 模板中出现的架构图类型

模板明确采用 UML 和“4+1”式视图说明。模板示例中实际出现：

1. **用例图**：演员、系统边界、主要用例及包含/扩展关系。
2. **逻辑分层图与包依赖图**：展示层、控制层、服务层、数据访问层以及包间依赖。
3. **分包图**：按 Action、Service、DAO 等包继续展开模块组成。
4. **类图/接口关系图**：展示核心类、接口、继承、实现、关联和多重性。
5. **部署图**：展示客户端、应用服务器和数据库节点及通信关系。

模板没有把活动图或顺序图列为每个 CRUD 模块的必交项。本项目额外增加一张 **GPS 定位入库顺序图**，用于解释设备密钥认证、事件幂等、事务入库和围栏状态推进，因为该动态流程仅靠静态类图不容易讲清。

## 5. 在 IDEA 中打开和截图

图源位于 [`docs/diagrams`](./diagrams/README.md)，全部为 PlantUML 文件；同源 PNG 位于 `docs/diagrams/rendered`。在 IntelliJ IDEA 2024.3.4 中安装或启用 PlantUML Integration 后，打开任一 `.puml` 文件即可在预览区显示。截图时建议：

1. 隐藏无关工具窗口，让编辑区和预览区同时可见。
2. 预览缩放到图中文字可读，窗口标题或项目树中保留当前 `.puml` 文件名。
3. 用系统截图工具截取 IDEA 窗口；七张图至少保留系统用例图、分层图、两张核心类图、部署图和 GPS 顺序图。
4. 图源变化后运行 `scripts/render-diagrams.ps1`，再替换说明书中的 PNG。

当前自动化环境无法读取本机原生 IDEA 窗口，因此交付的是可在 IDEA 直接预览的 `.puml` 源文件和完全同源的 PNG。IDEA 窗口外框截图需要团队在本机按上面步骤补拍，图的内容无需重新绘制。

## 6. Agent 岗位建议

现阶段不增加独立 Agent 开发工程师。若后续明确新增“自然语言查询统计口径、自动生成管理简报、基于权限检索业务数据”等功能，可先由胡吉涵负责数据工具与检索接口，钟毓林负责权限、审计和输出边界，李治宏负责对话界面，周虹宏负责验收口径与风险测试；工作量达到持续迭代规模后再考虑独立岗位。
