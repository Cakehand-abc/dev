## 2 拟支持环境

开发演示优先支持 Windows 与 MySQL 8.0；部署采用 Spring Boot 可执行 JAR，前端静态产物可随 JAR 打包实现同源访问。可补充 Linux 的部署步骤，但只有经过对应环境验证才能标记“已验证”。暂不要求外置 Tomcat、Redis 或 Docker。

Java 源码目标保留 17。Spring Boot 官方声明 3.5.16 支持 Java 17 至 25、Maven 3.6.3 以上，本机配置在该范围内；第三方依赖仍需构建验证。团队 IDEA 开发环境采用 JDK 17，避免把本机默认 JDK 25 的工具链要求带入较早 IDEA。https://docs.spring.io/spring-boot/3.5/system-requirements.html

测试采用 Boot BOM 管理的 JUnit Jupiter 5.12.2 和 JUnit Platform 1.12.2，显式声明 test scope 的 junit-platform-launcher，使测试运行器可使用项目提供的匹配版本。Maven test 生命周期由 Surefire 执行 JUnit，JUnit 并非 Maven 自带的一套替代测试框架；工程同时保留 IDEA 直接运行 JUnit 的路径。https://docs.spring.io/spring-boot/3.5/appendix/dependency-versions/coordinates.html

### IDEA 导入与测试验证

1. 从根目录 pom.xml 以 Maven 项目导入，执行 Reload All Maven Projects。
2. Project SDK 与 Maven Runner JRE 选择已安装的 JDK 17，语言级别为 17；不将 .idea 中的机器专属路径提交为统一配置。
3. 确认依赖树中的 junit-jupiter 为 5.12.2，junit-platform-launcher 与 engine 为 1.12.2，无 JUnit 6 残留。
4. 在 DevApplicationTests.contextLoads 左侧运行按钮直接运行 JUnit，记录 IDEA 完整版本、运行 JDK 和结果。
5. 另外执行 mvn test 或 .\\mvnw.cmd test，记录 Surefire 结果。直接运行 IDEA 测试和 Maven 验证是两个独立检查项。

当前尚未操作 IDEA 运行器；不会将命令行测试结果等同于 IDEA 验证结果。应用上下文测试使用 H2 临时内存库，生产配置仍使用 MySQL。团队最早的 IDEA 版本尚待补充，暂不宣称全部历史版本均兼容。

## 3 拟定端口和配置

| 配置 | 规划 |
| --- | --- |
| 后端 HTTP | 8080，仅本地联调时绑定 127.0.0.1 |
| 前端开发服务 | 5173，通过代理访问后端 /api |
| MySQL | 3306，以实际服务为准 |
| 数据库名 | smart_care，实施前检查同名库存在情况 |
| DB_URL | 环境变量提供 JDBC 地址、字符集和时区 |
| DB_USERNAME / DB_PASSWORD | 独立业务账号，不在源码保存真实密码 |
| SPRING_PROFILES_ACTIVE | local、demo、prod，模拟器仅 demo 启用 |
| 初始管理员密码 | 首次初始化从环境注入，不在部署包固定通用密码 |
| 地图模式 | 默认离线坐标画布；在线服务待单独配置 |

不得默认清空同名数据库。初始化脚本与重置脚本分开；破坏性重置仅在用户明确确认后执行。未获得账号配置前，不尝试猜测数据库密码，也不读取他人工程的凭据。

## 4 最终手册计划包含的流程

1. 软硬件要求、已验证版本矩阵、网络和磁盘空间要求。
2. JDK、JAVA_HOME、Maven、MAVEN_HOME 与 PATH 配置和版本检查。
3. MySQL 服务连接验证、创建业务数据库和最小权限账号、脚本执行次序。
4. 环境变量示例及 Windows PowerShell 设置方式，区分普通配置和敏感配置。
5. 前端 npm ci、构建；后端 Maven Wrapper 测试与打包；确认最终 JAR 路径。
6. 开发模式前后端分别启动，演示模式通过 JAR 同源访问。
7. 初始化演示数据、测试账号角色与首次密码设置、启动后八模块冒烟检查。
8. 日志目录、端口占用、数据库拒绝连接、依赖下载失败、时区和中文编码排查。
9. 停止服务、数据备份、恢复验证、版本回退；清晰标注可能覆盖数据的步骤。
10. 实际验证日期、操作者和结果。没有执行的环境或流程明确标记待验证。

命令细节将在工程完成后以真实产物路径补齐并执行核对。当前不提供看似可执行但指向尚不存在文件的部署指令。
